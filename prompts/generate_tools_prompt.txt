## Code standards

- **Runnable**: Before finishing, execute each file and fix any errors. Every file must import cleanly and its `if __name__ == "__main__"` block must complete without exceptions, demonstrating that the tools work on real or representative data.
- **Readable, not verbose**: Prefer clear variable names and structure over inline comments. Do not pad short functions with unnecessary commentary.
- **Dependencies**: Before writing any import, confirm the package is installed by running `python -c "import <package>"`. If a package is missing, use an available alternative or implement the functionality directly.
- **Avoid hard-coded values**: Hard-coded numbers are subject to hallucination. Use programmatic values whenever possible.
- **No global state**: Functions take explicit arguments and return explicit values.
- **Usage**: An agent should be able to use the tools like an importable package.
