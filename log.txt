       ## Key Methods for Learning Open Quantum Systems (oQMLA)
       
       The framework extends the Quantum Model Learning Agent to open systems by employing the Lindblad master equation. It uses a "double-nested optimization process" combining Bayesian inference for parameter estimation with a genetic algorithm for model exploration.
       
       ## Lindblad Formalism
       
       The approach models Markovian dynamics through: "∂ρ/∂t = Σᵢ αᵢ ℋ[hᵢ](ρ) + Σₖ Γₖ 𝒟[Lₖ](ρ)" where coherent evolution involves commutators and dissipative evolution uses jump operators (Lindblad superoperators).
       
       ## Model Selection and Comparison
       
       Models are ranked using Root Mean Squared Error (RMSE) as a fitness function: "f(m) = 1/RMSE ensures monotonic growth with model performance." This provides unbiased evaluation across different model branches and executions.

       # Quantum Model Learning Agent - Key Information
       
       **Title:** Quantum Model Learning Agent: characterisation of quantum systems through machine learning
       
       **Authors:** Brian Flynn, Antonio A. Gentile, Nathan Wiebe, Raffaele Santagati, Anthony Laing
       
       **Year:** 2021 (arXiv:2112.08409)
       
       ## QMLA Algorithm Overview
       
       The QMLA operates as a forest search through candidate Hamiltonian models. It systematically evaluates proposed models against experimental data from a target quantum system to identify which interactions actually govern the system's dynamics.
       
       ## Core Methodology
       
       **Model Structure:** Each model is characterized by constituent terms and their parameters: "H^′=α⃗′·T⃗′" representing a sum of interaction terms multiplied by scalar coefficients.
       
       **Iterative Process:** The algorithm follows a three-step cycle repeated across multiple "branches":
       - Train candidate models via Quantum Hamiltonian Learning (QHL)
       - Consolidate models through comparative evaluation

       The paper combines "sequential Monte Carlo and Bayesian experimental design" to infer dynamical parameters of quantum systems. The approach enables online learning during experiments without requiring post-processing storage.
       
       ## Sequential Monte Carlo Approach
       
       The SMC algorithm approximates posterior distributions using particles with weights. As described in the document, particles are updated sequentially: "the weights at each step are iteratively calculated from the previous step" through Bayes rule applications. Resampling occurs when effective sample size falls below thresholds to prevent particle degeneracy.
       
       ## Model Comparison Methods
       
       Models are evaluated using:
       - **Information gain utility function:** Minimizes expected entropy in posterior distributions
       - **Negative variance utility:** Optimizes mean squared error performance
       - **Bayesian Cramer-Rao bound (BCRB):** Provides lower bounds on achievable estimation error, allowing the algorithm to "certify its own performance"
       
       ## Likelihood and Model Evidence Equations
       
       For a single qubit example with dephasing:
       
       **Pr(0|ω;t) = e^(-t/T₂)cos²(ωt/2) + (1-e^(-t/T₂))/2**
       
       The posterior combines likelihood with priors via Bayes rule: "Pr(x|D;C) = Pr(D|x;C)Pr(x)/Pr(D|C)"
